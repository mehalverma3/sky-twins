# DECISIONS.md
- Streamlit + Python: fastest path to a deployed app for a first hackathon.
- skyfield + JPL DE421: free, accurate, covers 1900-2050.
- Wikipedia On This Day API over a hand-curated CSV: reproducible, larger, real data. Known bias toward wars/disasters/Western history.
- Pairwise angular separations, not raw positions: compares sky geometry (aspects).
- Planet weights by speed: my judgment, not validated.
- Codespaces: avoids local Windows setup problems.
